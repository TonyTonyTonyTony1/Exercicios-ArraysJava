# Exercícios de Arrays em Java

Este diretório contém 50 programas Java independentes, correspondentes à lista de exercícios fornecida.

## Organização

- `Exercicio01.java` até `Exercicio30.java`: arrays unidimensionais.
- `Exercicio31.java` até `Exercicio50.java`: arrays bidimensionais e matrizes.

Cada arquivo contém uma classe pública com o mesmo nome do arquivo e um método `public static void main(String[] args)`. Os programas usam Java básico e `Scanner` para entrada pelo teclado quando necessário.

## Como compilar e executar

É necessário ter o JDK instalado. Abra um terminal nesta pasta e compile um exercício, por exemplo:

```bash
javac Exercicio01.java
java Exercicio01
```

Troque `Exercicio01` pelo nome do exercício desejado. Para compilar todos os arquivos de uma vez:

```bash
javac Exercicio*.java
```

## Observações

- Os índices dos arrays e matrizes começam em `0`; as mensagens de busca informam isso quando relevante.
- Nos relatórios de alunos dos exercícios 28 e 38, foi adotada a regra de aprovação com média/nota maior ou igual a 7, em consistência com o exercício 17, pois o enunciado desses relatórios não especifica outro limite.
- No exercício 29, o menu é apresentado uma vez após o cadastro dos cinco produtos, conforme o enunciado.
